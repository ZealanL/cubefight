# CubeFight
A Minecraft 1.8.9 combat simulation in optimized Rust

## Current features:
- Accurate basic movement + block collisions
- Visualization with player models and blocks
- Half-server emulation of packet transmission (serverbound-only)
- Accurate attack logic (knockback, hit tracing, sprint hits, etc.)
- Player sequence recording mod (legacy fabric 1.8.9) and auto-comparison testing to recorded data
